# 能量电池逃生 — 概念与设计（中文原稿）

**文档类型：** 第一部分 — 概念与设计（评估交付物）
**引擎：** Unity 2022.3 LTS（2D）
**作者：** Zhixin Zhu（学生）

---

## 1. 概述

《能量电池逃生》是一个小巧、完整、自包含的 2D 街机小游戏。玩家控制一个被困在封闭
房间里的机器人，需要收集散落在房间中的 3 个能量电池，然后到达出口逃生。一个敌人在
房间内随机移动，碰到玩家立即结束回合。每局限时 180 秒。

设计的核心目标是“小而完整”：一个房间、一个敌人、三个收集物、清晰的胜负判定，以及
内置的无障碍支持。单局约 2–4 分钟，很适合作为评估演示。

## 2. 目标用户与平台

- **用户：** 休闲玩家与评估者，任何会使用键盘的人。
- **平台：** 桌面端（Windows / Mac / Linux）Unity 播放器。仅需键盘，无需手柄或鼠标。
- **单局时长：** 2–4 分钟。

## 3. 核心循环

1. 回合开始：倒计时 180 秒。
2. 玩家探索房间并收集电池（`B1`、`B2`、`B3`）。
3. 敌人随机游走；玩家需避免碰到它。
4. 碰到敌人立即结束回合（Game Over）。
5. 集齐 3 个电池后，出口解锁（红→绿，`LOCKED`→`OPEN`）。
6. 到达已开启的出口即胜利；碰到敌人或时间耗尽则失败。

## 4. 机制细节

| 元素 | 行为 |
|------|------|
| 玩家 | 俯视移动（WASD / 方向键）。动态刚体，被墙阻挡，不能离开房间。 |
| 能量电池 | 触发拾取。拾取后隐藏、计数 +1、播放音效。 |
| 出口 | 触发区域。集齐前锁定（红），集齐后开启（绿）。开启时进入即胜利。 |
| 敌人 | 房间内随机游走（3 u/s，每 1–3 秒重选随机目标，从不追击）。**碰到它立即结束游戏（Game Over）。** |
| 命数 | 一次接触即结束回合，没有额外命数缓冲，生存意味着全程避开敌人。 |
| 计时 | 180 秒倒计时，归零失败。 |

## 5. 操作

`W A S D / 方向键` 移动；`R` 重开；`C` 高对比度；`M` 静音；`[` / `]` 音量；`I` 帮助。

## 6. 关卡布局

房间为 20×12 世界单位的矩形，四面为实心墙。物体布置使玩家必须绕房间移动，至少一次穿过敌人常出没的区域：
玩家出生左下 `(0,-3.5)`；`B1(-6,0)`、`B2(6,0)`、`B3(0,3)`；出口在顶部中央；敌人
从 `(-5,-2)` 出生，之后在房间内随机游走。正交摄像机（size 6.5）框住整个房间。

## 7. 软件架构

项目刻意不放置手工物体。单一引导器在代码中构建一切，避免易碎的序列化引用，便于重开
重建：

`RuntimeInitializeOnLoadMethod` → `GameBootstrap.Init()` 创建 GameManager、
SettingsManager、AudioFeedback、HUDManager、InstructionsPanel，再调用
`LevelBuilder.Build()` 生成摄像机、四面墙、玩家、3 个电池、出口与敌人。

## 8. 无障碍设计

高对比度模式（`C`）、全局静音与音量（`M`、`[`、`]`）、状态不只有颜色（标签、`LOCKED`/
`OPEN`、`!`）、大号易读文字。

## 9. 美术与音频

**无任何外部资源**：精灵由 `GameArt` 在运行时绘制为 `Texture2D`；音效由
`AudioFeedback` 用 `AudioClip.Create` 合成短正弦音；字体使用 Unity 内置 Arial。

## 10. 测试计划

手动验证胜利路径与两种失败路径、碰撞与触发、无敌窗口、无障碍切换、重开，以及独立打包
后关卡可加载。

## 11. 风险与对策

序列化引用跨机失效 → 全部代码生成；难度失衡 → 速度/半径可调；文字难读 → 大字体 + 高
对比度；打包缺场景 → README 写明“Add Open Scenes”。

## 12. 范围边界

多房间、计分榜、存档、触屏、联网均不在本次范围内；设计留有扩展点（更多巡逻点、更多
电池）。
